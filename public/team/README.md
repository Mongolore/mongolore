# Багийн гишүүдийн зураг

Файлын нэрийг `data/team.ts` доторх `photo` талбартай тааруулна:

- `khaliun.jpg` — Халиун
- `enerel.jpg` — Энэрэл
- `barkhas.jpg` — Бархас
- `nymaa.jpg` — Нямаа
- `amgalan.jpg` — Амгалан

Дөрвөлжин (1:1), 400×400 px орчим зураг тохиромжтой.
Зураг байхгүй бол нэрийн эхний үсгээр автоматаар орлуулна.

Эх зургийг дөрвөлжин болгож тайрахдаа:
`node scripts/prepare-team-photos.mjs` (эх зургууд `~/Downloads` дотор).
